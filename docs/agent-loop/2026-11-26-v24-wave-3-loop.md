## Integration review

The wave's five PRs are internally consistent and conservative (every new check fails closed, the loop writes no settings, the lock is released on every exit path), but two of them meet badly: the 'locked' outcome 3.2 added to verify mode is not read by the settle-main gate 3.5 added, so a lock contention during a revert can let the next merge proceed onto a red default branch. The new libraries also copy rather than reuse: deps.js duplicates escaped.js's PR listing and default-branch lookup (and lacks its origin/main fallback, which can park a whole relaunch), isolation.js duplicates permission.js's settings parsing, and dep-state.js duplicates escaped.js's spawn helper. The rest is nits: unused exported constants, a redundant exclude line and one extra preflight relay per wave.
