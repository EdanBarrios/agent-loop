## What happened

4.2, 4.1 and 4.3 ran in the loop as designed (4.1 waited for 4.2's run-record schema, as the spec review asked).
4.1's and 4.T's workers took over two hours each: their tests start real `git`, `node` and CI runner processes, and on
this 8 GB Mac macOS's program check (`syspolicyd`) fell behind on them until every new process waited at launch. The
same tests run in under a minute on CI.

4.T's quick check then hung for 87 minutes, the machine was restarted twice, and the tail was relaunched once with
its open PR. Its last finish attempt hung again, so the session stopped the run and asked the critic directly. The
critic found the cause in the test itself: `gh pr checks --watch` runs in process and blocks the event loop, so
vitest's timeout could never fire, and the detached CI runners outlived a failed test and kept feeding the stall.
The session applied the six fixes (a deadline per watch, a 60 s bound per CI command, killing leftover runners) and
the critic approved round 2. The merge script itself then stalled at process launch, so the session merged with
`gh pr merge --match-head-commit` pinned to the reviewed head, after CI had passed.

No integration review ran, because the wave's run never reached its end.

## Follow-ups

- `bench/ci.js`: detached runners have no overall deadline and no way to stop every runner under a state directory;
  a hard kill of the test or the session still leaves them running (the critic's follow-up A).
- `bench/fake-gh.js`: `pr checks --watch` has no deadline of its own; in-process callers must pass `sleep`.
- Wave 3's integration review: four medium findings (duplicated settings readers and `gh pr list` arguments, a
  `locked` result in verify mode, default-branch detection through `origin/HEAD` only) and the critic's medium
  finding on 3.2 (a verify relay can be cut off mid-revert by the 10-minute relay limit).
- Environment: run waves on this machine with the developer-tools exemption for Terminal, or with fewer
  process-heavy tests at once; the stall cost more time in this wave than all the agents together.
